# Theobroma Bakery Clone

This is a frontend-only HTML, CSS, and JavaScript project. Open `index.html` directly in a modern browser; no Node.js, npm, XAMPP, MySQL, or web server is needed.

Customer accounts, login sessions, carts, and administrator product changes are stored in that browser's localStorage. They remain available after refreshes on the same browser/device. Clearing browser site data resets the demo data.

## Admin login

Use the existing login popup with:

- Email: `admin@theobroma.local`
- Password: `Admin@123`

The admin can add, edit, and delete products from the existing Products page, and view customer cart items from the Cart page. This is a local demo account, not a secure production authentication system.
